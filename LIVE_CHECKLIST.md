# Real trading is absent

Only paper mode and PaperExecutor exist. No CLI command, test gate, approval file,
AI response, or report can enable real orders. This file is not an unlock.

Any future real system would be separate engineering requiring explicit human
scope and authorization, a reviewed execution design, secure credential custody,
independent security review, verified token/pool safety, observed execution data,
validated controls, billing reconciliation, operational monitoring, and a new
assessment of legal and financial requirements. Those systems are not built here.

A paper review pass and a replication proposal establish neither real available
funds nor expected future performance. This task does not authorize real trades,
wallet access, cloud purchases, account creation, or fund transfers.
